# 産技品川 2026B メインリポジトリ

都立産業技術高等専門学校 品川キャンパス Bチームのメインリポジトリです。

このリポジトリでは、2026年度高専ロボコンで使用した各リポジトリをサブモジュールとして管理しています。

## Clone

サブモジュールを含めて取得してください。

```bash
git clone --recursive git@github.com:TMCIT-S-Robocon/2026B.git
```

既にクローン済みの場合は、以下を実行してください。

```bash
git submodule update --init --recursive
```
